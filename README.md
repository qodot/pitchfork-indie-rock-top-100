# Indie Rock Top 100

Pitchfork's [The 100 Best Indie Rock Albums of All Time](https://pitchfork.com/story/the-100-best-indie-rock-albums-of-all-time/), ranked 1 to 100, in six fan-made skins.

| Page | Style |
| --- | --- |
| [vintage.html](vintage.html) | Late-90s homepage with a Winamp-style player |
| [zine.html](zine.html) | Photocopied indie rock zine |
| [crate.html](crate.html) | Record store crates and a listening station |
| [posters.html](posters.html) | Wall of silkscreen gig posters |
| [radio.html](radio.html) | College radio DJ booth and program log |
| [vhs.html](vhs.html) | Late-night music video channel on a CRT |

Each album links to its entry in the original story via a text fragment link. No review text is reproduced here.

Unofficial and non-commercial. The ranking and reviews belong to Pitchfork, and cover art loads from Pitchfork's image server.
